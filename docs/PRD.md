# SmartReco AI

## Overview

SmartReco AI is an AI-powered behavioral recommendation platform.

Users browse products or courses.

Every interaction is tracked.

An AI Recommendation Agent analyzes user behavior, retrieves relevant products using semantic search, and generates personalized recommendations.

---

## User Roles

### User

- Register
- Login
- Browse products
- Search products
- Receive recommendations

### Admin

- Login
- Create products
- Edit products
- Delete products
- View analytics
